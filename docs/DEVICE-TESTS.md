# 印记相机 1.1.1 · 真机验收清单

用户已确认1.0.1拍照正常；以下是1.1.1需要重新执行的验收，不是已通过项目。

## 流畅取景、大画面与超广角
- [ ] 无调色/LIVE关闭时移动手机，取景无明显旧版15～20fps观感；记录实际体验，不把源码目标当实测。
- [ ] 开调色后GPU预览方向、镜像、颜色和原生预览一致；若异常回退提示明确。
- [ ] 开启“流畅优先”后系统预览丝滑，成片仍包含调色与水印；关闭可恢复GPU。
- [ ] 静态/日期/多图片水印不引起每秒明显停顿，时间文本按秒刷新。
- [ ] 375pt小屏照片满宽，视频满宽16:9，无画面拉伸/错误裁切；按钮不被浮层挡住。
- [ ] 横屏旋转、大字体、前后台、权限弹窗返回后无黑屏、上下翻转或失去取景。
- [ ] 有超广角的后置相机出现0.5×，实际视野比1×明显更宽；1×为主摄基准。
- [ ] 无超广角机型不出现假0.5×；2×行为符合硬件/系统选择，不宣称光学长焦。
- [ ] 超广角快捷键、连续滑杆、双指同步，快速拖动不积压，前后镜头/模式互切正常。
- [ ] 0.5×普通照片和LIVE各拍一张，水印及调色完整；录10秒超广角视频有声音。
- [ ] 新版仍可导入旧模板，EV和Live设置保持，原待保存作品可恢复。


## Live Photo 与界面新增项
- [ ] 普通照片在 LIVE 关闭时仍正常，旧模板和暂存作品不丢失。
- [ ] 顶部 LIVE 开关开启后提示麦克风权限；拒绝时不伪装拍摄成功。
- [ ] 前后摄像头均检查 Live 支持，切换镜头/照片与视频模式后状态准确。
- [ ] 后置和前置各拍实况，系统相册显示 LIVE，长按有动态画面和声音。
- [ ] 主照片和动态部分都包含文字/PNG水印与调色；方向、镜像、位置一致。
- [ ] 开启保留原片时，成片和原片均是可播放的 Live Photo。
- [ ] 实况合成取消/切后台后原始 JPG+MOV 保留，待保存可重试成对保存。
- [ ] 配对校验失败时有提示，不静默保存为普通照片。
- [ ] 原EV位置显示倍率缩放，滑杆和双指同步，不误触对焦。
- [ ] 缩放到最小/最大值不会超出当前摄像头限制，切换镜头后数值准确。
- [ ] 设置按钮直接打开EV滑杆，-2～+2 EV返回取景后生效；重开App保留。
- [ ] 点击曝光归零恢复0 EV；不影响滤镜亮度设置。
- [ ] 小屏竖屏横屏，顶部标题/LIVE/水印/设置不重叠，倍率滑杆可触控。

## 安装与权限
- [ ] 使用有效签名/描述文件重签 IPA 后可安装、可首次启动。
- [ ] iOS 26.5 目标机不黑屏、不闪退；图标显示正常。
- [ ] 首次相机权限允许后显示画面；拒绝后仍可编辑模板。
- [ ] 麦克风在使用有声录像或实况照片时请求；拒绝时不静默录无声视频。
- [ ] 相册仅请求添加照片权限；拒绝后成品进入待保存。
- [ ] 从设置重新授权后，相机与相册保存可恢复。

## 相机
- [ ] 前后摄像头切换，4:3照片取景和最终照片范围一致。
- [ ] 点击对焦、双指缩放、EV补偿有效。
- [ ] 关闭/自动/开启闪光，前置不支持时不报错；录像开启补光灯后停止会熄灭。
- [ ] 3秒/10秒倒计时；倒计时切后台能取消且回前台可再次拍摄。
- [ ] 连续拍摄30张，无主线程堆积、闪退或丢失。
- [ ] 横屏左右两个方向、前后镜头镜像开关，预览/照片/视频方向一致。

## 调色与水印
- [ ] 亮度、对比度、饱和度、冷暖四项实时预览；原图预设可复位。
- [ ] 编辑器背景没有重复调色，水印颜色不被调色影响。
- [ ] 文字、日期、透明PNG在成品上可见，不只是界面叠层。
- [ ] 每次拍摄时间自动更新；视频时间固定为开始录制时。
- [ ] 多行中文/emoji、长文本、描边或阴影、半透明背景不截断或崩溃。
- [ ] 文字、图片随拖动/缩放/旋转准确变化；大小按画面短边比例保存。
- [ ] 颜色、透明度、字体、粗体、锁定、复制、删除、图层前后顺序有效。
- [ ] 6种预设可用；图片预设可找到捆绑的stamp资源。
- [ ] 自定义模板保存、切换、删除；退出App重开设置仍在。
- [ ] 导出备份后删除一个临时测试模板，再导入能够恢复模板/PNG。
- [ ] 非法JSON、超大文件、伪装图片、路径穿越名称被拒绝，不污染已有设置。
- [ ] 导入大图片时界面不长时间冻结，图片按上限缩小。
- [ ] 图片图层资源卸载App后不可默认恢复；导出备份可恢复。

## 录像、合成与失败恢复
- [ ] 10秒/60秒/300秒视频有声音、画面不卡死，输出方向正确。
- [ ] 视频目标1080p30（设备支持时），输出不带预览UI、选中圆环或九宫格。
- [ ] 视频水印位置和预览一致，水平/垂直镜像没有反转文字。
- [ ] 点击停止/达到5分钟上限均触发合成并保存。
- [ ] 合成进度可见；取消后原始视频保留，待保存可重试。
- [ ] 录制中来电话或切后台：停止/中断后留有恢复文件。
- [ ] 合成中切后台：取消或保存恢复信息，不误删原片。
- [ ] 拒绝相册权限、低存储、合成失败时文件不会自动删除。
- [ ] 开启保留原片，相册出现原片与成片两份；关闭只有成片。
- [ ] 待保存分享和删除二次确认正常；不误删其他作品。
- [ ] 保存成功后Pending相应文件清理，无无声重复保存。

## 性能和边界
- [ ] iPhone 13 mini小屏竖屏/横屏，编辑器画布与设置没有重叠或约束异常。
- [ ] 深色系统、动态字体、键盘打开和关闭不遮挡完成按钮。
- [ ] 内存、发热、电量消耗在可接受范围，长录制不被系统终止。
- [ ] 关闭相机权限/系统媒体服务重启可恢复，不无限加载。
