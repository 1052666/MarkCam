# 1.1.0（3）实况照片与相机界面更新

## 用户可见变化
1. 顶部新增 LIVE 开关；「设置」中也可开启。默认关闭，保持普通拍照兼容性。
2. 原取景底部 EV 滑杆改为缩放，显示当前倍率；滑杆与双指控制同一摄像头缩放值，按当前镜头能力限制范围。
3. EV 曝光补偿移到「设置」顶部，范围-2～+2档，保存到本机并提供一键归零。

## Live Photo 技术路径
- 使用 `AVCapturePhotoOutput` 的原生 `livePhotoMovieFileURL`，不是从任意视频伪装的动图。
- 完整主照片与短视频先保留在 `Documents/Pending`，在系统拍摄结束回调后等待两个资源均已写完。
- 主照片通过原有水印引擎渲染，重新写入原生 Apple MakerNote 配对标识。
- 动态视频通过 AVAssetReader/Writer 编码水印和调色画面；原始声音与定时元数据轨道透传，保留 QuickTime content identifier、still-image-time 和轨道关联。
- 输出经 ImageIO 重读校验照片配对标识，再使用 `PHLivePhoto` 请求验证。最终成片必须被系统识别为完整实况，才进入相册保存。
- 同一个 `PHAssetCreationRequest` 添加 `photo` 与 `pairedVideo`，不把二者拆成独立相册照片/视频。
- 不申请读整个图库的权限；仍使用仅添加照片权限保存。

## 数据与兼容性
- 水印设置schema保持1，新增livePhotoEnabled=false和exposureBias=0；旧模板缺少新字段时自动补默认值。
- 保留原片选项对实况保存两个完整Live资产；原始素材删除仅发生在相册写入成功后。
- 配对/合成失败不会静默存普通照片。待保存支持重试和导出JPG+MOV素材。
- 合成可取消，切后台会取消处理并保留素材；最多120秒处理超时防止无限忙碌。
- Live录音需要麦克风授权。当前不提供无声Live模式；不支持实况的摄像头/格式显示提示。
- 开启Live和切换镜头会重配系统管线；取景稳定后再拍，动态长度由系统自动裁剪，通常约3秒。
- 普通视频最高5分钟的原有限制不变；本版未增加超广角/长焦光学镜头选择。

## 校验边界
- 使用真实iOS16.5 SDK编译链接arm64，普通照片+Live三个必要回调受required协议和-Werror=protocol保护。
- 已通过170项包结构/二进制/源码断言、36项主机侧倍率布局模型与静态契约、正反编译回归。
- 这些检查不能证明真机Live播放/声音/水印/方向正确；必须安装测试。本环境没有执行iOS App。
- v1.0.1拍照正常已获用户确认；v1.1.0新增功能待验收。

## 快速复测
用原签名身份和BundleID覆盖安装；不要卸载，建议先导出模板。
1. LIVE关闭拍一张普通照片，确认旧路径正常。
2. 开LIVE、授权麦克风，画面稳定后拍摄，合成成功后到系统相册长按播放。
3. 前后摄像头各试一次，检查水印文字方向和动态部分颜色。
4. 拖缩放条，再双指缩放，确认倍率同步；设置中改EV返回取景，重开后确认保留。
5. 若Live未完成，截图具体错误；保留待保存文件，不要卸载。
