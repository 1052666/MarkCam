# 印记相机 1.1.1（4）— 流畅取景、大画面与超广角

## 三项合并更新

### 1. 取景卡顿修复
源码确认1.1.0取景有`1/20秒`节流，并为每个显示帧生成两张CGImage/UIImage（调色和原图）。30Hz等间隔输入时，该节流在主机侧时间模型中仅接收每两帧中的一帧，约15fps。**这不是对用户手机实际帧率的测量**，但属于明确的实现缺陷。

本版：
- 无调色直接使用AVCaptureVideoPreviewLayer系统原生预览。
- 有调色时以Core Image + Metal输出到CAMetalLayer，不走逐帧UIImage读回。
- 预览优先使用系统预览尺寸YUV缓冲；GPU纹理最长边1280，原生照片、视频和Live成片尺寸不因此降低。
- GPU最多两帧在途，过期帧丢弃而不是排队；只在进入编辑器时取一次原图快照。
- 水印另用后台队列渲染；静态模板缓存，含时间占位符时才随秒更新。
- 只修改水印/滤镜不再反复重配摄像头；曝光/镜像/Live等真正影响硬件的设置才更新会话。
- 镜头滑杆请求合并为最新值，避免快速拖动积压。
- 设置新增“流畅优先（取景不调色）”：开启后始终原生预览，水印仍可见、调色仍应用到成片。默认关闭以保留实时调色习惯，GPU不可用时明确提示回退原生。

不承诺原相机相同帧率，不声明30/60fps实测通过。设备、光线、发热和Live缓冲仍会影响流畅度。

### 2. 大取景界面
- 去掉旧圆角卡片和左右留白，照片按实际画幅尽量满宽。
- 以375×812、top50/bottom34的主机几何示例，4:3照片为375×500pt；旧版351×468pt，面积约增14%。这是布局计算，不是真机截图。
- 竖屏视频采用满宽16:9画面，快门/模式可浮在下方画面上，不裁切或拉伸取景内容。
- 快门、模式、模板编辑集中到底部；顶部保留水印、LIVE、设置。普通状态提示自动淡出。
- 横屏控制靠右。极小屏仍按可用空间缩放，确保按钮不超出屏幕。
- [布局示意](layout-review.html)由相同C布局函数输出坐标生成，不是App截图或UIKit运行记录。

### 3. 真实后置超广角
- 后置优先选择Triple/Dual Wide虚拟多摄像头，其次Dual/Wide，允许系统管理实际物理镜头切换。
- 使用系统`constituentDevices`和`virtualDeviceSwitchOverVideoZoomFactors`建立主摄1×基准，避免把虚拟设备hardware factor=1误标成主摄1×。
- 支持超广角的机型会有0.5×附近的实际最广视角快捷项（取决于系统镜头标定），以及1×、2×和设备提供的其他快捷倍率。
- 快捷按钮、倍率滑杆和双指同步；前后镜头/照片录像互切后恢复显示倍率。
- 2×只是快捷缩放，不保证该机有2×光学长焦。部分倍率与光线下系统可自动选择裁切或其他物理镜头。
- 无超广角硬件时不显示假0.5×，不靠缩小图片伪造广角。
- 录像开始后仍锁定镜头与缩放；本版没有增加录制中跨镜头切换。

## 兼容与验收
- Bundle ID、模板schema和Pending恢复格式不变。原实况处理模块保持1.1.0相同源码。
- 仅交叉编译、主机执行纯C布局/倍率函数和静态/二进制/编译正反回归；没有运行iOS App。
- 安装需合法重签；保持原签名身份和Bundle ID覆盖安装，不要卸载，先备份模板。
- 请复测：0.5×视野是否真实变宽；1×是否主摄；原生/GPU画面方向镜像；前后台恢复；普通照片、超广角Live和有声视频保存；EV设置是否保持。
- 若仍卡顿，优先试“流畅优先”，反馈LIVE开关状态、调色是否开启、光线及问题步骤。日志或私人素材不要提交公开仓库。
