# MarkCam 1.3.0 (7)

本版把快门恢复、连续拍摄和原生界面改造合并为一次更新。最低系统仍为 iOS 16.5，Bundle ID 和已保存模板格式保持兼容。

## 拍摄

- 普通照片在曝光结束后即可继续按快门，最多两张在途；每张照片独立持有回调、设置和文件写入状态。
- 水印合成、调色和相册保存使用有界后台队列。待处理作品、Live Photo、录像、内存和温度限制仍会影响可拍状态；界面会说明等待原因。
- 默认开启“连拍优先”。它优先缩短等待，弱光细节可能减少；在“设置”中关闭即可使用画质与速度平衡策略。
- 双环快门立即响应按下，不添加弹跳或等待动画；停止录像使用明确的方形标记。
- 用作品计数显示待处理队列。水印和 Live 使用图标、文字、选中边框与辅助功能状态，不只靠颜色表达状态。

## 水印工坊

- “图层 / 调色 / 模板 / 设置”四个入口减少长列表滚动。相机右上角设置直接打开设置页。
- 保留所有原有图层、文字、日期、图片、模板备份和调色能力。
- 拖动、缩放、旋转和连续调色时即时更新预览；松手、取消操作、切换工具、离开编辑器或应用被中断时再保存。VoiceOver 的离散滑块调整会立即保存。
- 图层、调色和模板页保留预览，大字体时缩小预览；设置页直接显示完整表单。
- 相机按钮、镜头选择和滑块提供至少 44pt 触控区；编辑表单支持 Dynamic Type。相机固定布局的短标签采用有上限的字体缩放，并提供完整 VoiceOver 标签。
- 减少透明度或高对比度使用实色操作区；减少动态效果关闭自定义提示淡出，触摸状态仍即时可见。系统表单、菜单、滚动使用 UIKit 行为。

## 设计依据

按 [emilkowalski/skills](https://github.com/emilkowalski/skills/tree/d23d7f88a2e21c9e4b1418c7abe420f5c1052ba7) 中的 `emil-design-eng`、`apple-design` 和 `review-animations` 指导改造。应用频率原则、即时反馈、原生控件、清晰状态、减少动态效果和布局稳定性；网页专属的 CSS 实现建议映射为 UIKit 行为。

## 验证与边界

CI 执行真实照片代理的受控回调测试、SDK 正反编译、原生 C 队列/布局检查、IPA 校验，以及标准屏和小屏 iOS Simulator 中的 UIKit 操作与截图检查。二进制附有对应提交的 JSON 报告和 SHA-256 清单。

模拟器中的取景图明确标为“模拟取景 · UI 检查”，只用来检查控件布局、文字、选中状态、横屏和大字体。模拟器快门用受控事件接收器检查按钮交互，不代表传感器拍摄、照片质量或实测 FPS。仍需真机复测普通照片连续拍摄、弱光、Live Photo、录像、后台恢复和相册写入。

IPA 为 arm64，只有 ad-hoc Mach-O 签名。安装前需要使用有效签名与描述文件重新签名；没有附带开发者证书。

## 真机复测

1. 新安装和覆盖升级后，确认已有模板恢复。打开、关闭水印，切换模板后各拍一张。
2. Live 关闭时连续轻点快门 10 次，记录拍摄反馈、待处理计数与系统相册中的实际照片数。队列满后等待恢复，再拍一次。
3. 编辑器拖动滑块或图层，松手后返回相机；重开应用，确认设置和图层位置一致。
4. 分别打开 Live、前置镜像和录像，确认画面方向、配对播放、声音及保存结果。
5. 开启最大的辅助功能字体、减少动态效果、减少透明度及 VoiceOver，检查设置页滚动和所有按钮的语音状态。
6. 拍摄或合成途中切换到后台、再回到前台；拒绝相册权限后重新授权，确认原片保留和快门恢复。
